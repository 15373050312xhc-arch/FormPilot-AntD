How It Works

1

DUMP

Local Playwright script extracts the Ant Design form schema + LLM prompt

→
2

PLAN

Paste prompt into ANY LLM client (Doubao / DeepSeek / Kimi / ChatGPT / Claude)

→
3

APPLY

Local script replays the LLM's JSON plan into the live form

Key Features

🔄

LLM-Agnostic

Switch Doubao / DeepSeek / Kimi / ChatGPT / Claude per form — no code changes.

🆓

Zero-Cost

Use any LLM subscription you already pay for. No API keys, no per-fill billing.

👤

Human-in-the-Loop

Every value is visible in a plain JSON plan before it touches the form.

🎨

Ant Design Native

Dedicated scanners for .ant-select, .ant-picker, .ant-cascader — fields generic tools skip.

🏷️

Label-Text Matching

Radio/select matched by visible text (pick_label) — survives internal value renames.

🛡️

Re-render Resilient

Re-stamps temp anchors and retries on React re-renders — no manual restart.

🔒

No Extension, No Telemetry

Local Python script + your own Edge profile. Runs only when you launch it.

✋

Never Auto-Submits

You review every field before clicking submit. Safety by design.

Quick Start

git clone https://github.com/15373050312xhc-arch/FormPilot-AntD.git
cd FormPilot-AntD

# Windows: double-click RUN.cmd
# Or: py launcher.py

# [1] Dump form schema → click purple "Dump Form" button
# [2] Copy outputs/form_prompt.txt → paste into your LLM
# [3] Save returned JSON as outputs/form_plan.json
# [4] RUN.cmd → [2] Apply form plan → click green "Apply Plan"
